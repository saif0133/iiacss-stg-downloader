Dooblo → SPSS

Connect to SurveyToGo, search for a project, choose its surveys, and download each selected survey as a separate .sav file.

Credentials stay in this tab only

1. Dooblo login

2. Find project

Uses STG SOAP server-side search when available; falls back to REST indexing automatically.

3. Select surveys to export

Each survey can be downloaded as its own SPSS file or as a Word questionnaire. The questionnaire is built from Dooblo GetSurveyXML and includes the question text, variable/Short ID, and coded answer choices when available. The SPSS export still uses SimpleExport in sequential batches.
